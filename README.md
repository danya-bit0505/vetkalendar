# ВетКалендарь

Календарь сроков родов для домашних и сельскохозяйственных питомцев: собаки, кошки, козы, коровы, свиньи. Считает окно родов по дате вязки, ведёт чек-листы, температуру, приплод, историю, персональную и породную адаптацию прогноза — и подсказывает удачную дату вязки, чтобы роды не совпали с запланированной поездкой.

Работает как один HTML-файл без сервера и базы данных: все данные хранятся в браузере (localStorage), с опциональным бэкапом в приватный репозиторий GitHub.

---

## 1. Быстрый запуск без GitHub

Файл `index.html` — это готовое приложение. Можно просто открыть его двойным кликом в браузере на телефоне или компьютере — всё уже работает, данные сохраняются локально.

Развёртывание на GitHub Pages нужно, только если хотите открывать приложение по постоянной ссылке и/или использовать бэкап данных.

---

## 2. Развёртывание на GitHub Pages

### Шаг 1 — создать репозиторий для сайта

1. На GitHub нажмите **New repository**.
2. Название — любое, например `vetkalendar`.
3. Видимость — **Public** (для бесплатного плана GitHub Pages работает только с публичными репозиториями; см. раздел про приватность ниже — сам код приложения не содержит ничьих личных данных, поэтому публичный репозиторий безопасен).
4. Создайте репозиторий.

### Шаг 2 — загрузить файлы

Загрузите в корень репозитория оба файла из этого комплекта:

- `index.html`
- `.nojekyll`

Через веб-интерфейс: **Add file → Upload files** → перетащить оба файла → **Commit changes**.

### Шаг 3 — включить GitHub Pages

1. **Settings → Pages**.
2. **Source**: Deploy from a branch.
3. **Branch**: `main`, папка `/ (root)`.
4. Сохранить.

Через 1–2 минуты сайт появится по адресу:

```
https://<ваш-логин>.github.io/<название-репозитория>/
```

Эту ссылку можно сохранить на телефоне как значок на главном экране — приложение будет открываться как обычное.

## 3. Бэкап данных в GitHub (необязательно, но рекомендуется)

Приложение умеет сохранять данные в отдельный JSON-файл в репозитории — это защищает от потери данных при очистке кэша браузера.

### Важно про приватность

Репозиторий с *сайтом* (шаг 2) — публичный, но его код одинаков у всех и не содержит личной информации.
Файл с *данными* (клички, даты вязок, **даты поездок**) — личные сведения, и даты поездок особенно чувствительны: они фактически показывают, когда владелец отсутствует дома. Поэтому для данных нужен **отдельный приватный репозиторий**, а не тот же самый, где лежит сайт.

Приватные репозитории на бесплатном плане GitHub — без ограничений, платный план для этого не нужен (Pages от них не требуется, они используются только как хранилище через API).

### Шаг 1 — создать приватный репозиторий для данных

1. **New repository** → название, например `vetkalendar-data`.
2. Видимость — **Private**.
3. Создать (можно пустым, без файлов).

### Шаг 2 — создать токен доступа

1. **Settings профиля** (не репозитория) → **Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Repository access**: Only select repositories → выбрать именно `vetkalendar-data`.
3. **Permissions → Repository permissions → Contents**: Read and write.
4. Сгенерировать токен и скопировать его (он показывается один раз).

### Шаг 3 — настроить приложение

В приложении откройте вкладку **⚙️ Настройки** и заполните:

| Поле | Значение |
|---|---|
| Personal Access Token | токен из шага 2 |
| Репозиторий | `<ваш-логин>/vetkalendar-data` |
| Файл | `vetcal-data.json` (можно оставить по умолчанию) |
| Ветка | `main` |

Нажмите **Сохранить настройки**, затем **↑ Сохранить в GitHub** — приложение создаст файл с данными в приватном репозитории. Дальше данные будут сохраняться туда автоматически при каждом изменении.

Если открываете приложение на новом устройстве или после очистки кэша — зайдите в Настройки и нажмите **↓ Восстановить из GitHub**, либо просто откройте приложение: при пустых локальных данных и настроенном GitHub оно попробует восстановиться само.

## 4. Установка на домашний экран телефона

После того как сайт развёрнут на GitHub Pages (раздел 2), приложение можно добавить на домашний экран — оно будет открываться как обычное приложение, без адресной строки браузера.

**iPhone (Safari):**
1. Откройте ссылку сайта в Safari (именно в Safari, не в другом браузере).
2. Нажмите кнопку **Поделиться** (квадрат со стрелкой вверх) внизу экрана.
3. Выберите **«На экран «Домой»»**.
4. Нажмите **«Добавить»**.

**Android (Chrome):**
1. Откройте ссылку сайта в Chrome.
2. Нажмите на три точки в правом верхнем углу.
3. Выберите **«Добавить на главный экран»** или **«Установить приложение»** (может появиться само как баннер снизу).
4. Подтвердите.

После этого на домашнем экране появится значок ВетКалендаря — при открытии сайт запускается на весь экран, без строки браузера.

## 5. Состав комплекта

```
index.html            — само приложение (открывать в браузере)
.nojekyll              — служебный файл для GitHub Pages, не трогать
manifest.json           — описание приложения для «Добавить на домашний экран»
icon-192.png            — значок приложения (Android)
icon-512.png            — значок приложения (Android, крупный)
apple-touch-icon.png    — значок приложения (iPhone/iPad)
favicon.png             — иконка вкладки браузера
README.md               — этот файл
```

Все файлы нужно загрузить в **корень** репозитория — рядом друг с другом, без вложенных папок.

## 6. Обновление приложения в будущем

Чтобы обновить сайт, просто загрузите новую версию `index.html` в тот же репозиторий (**Add file → Upload files**, заменить существующий) — GitHub Pages обновится автоматически в течение минуты. Данные при этом не теряются: они хранятся отдельно от кода — в localStorage и приватном репозитории с данными.
